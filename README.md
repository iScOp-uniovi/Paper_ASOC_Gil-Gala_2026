## 📄 Description
This repository contains supplementary material for the paper:

> **"Evolving ensembles of routing policies for the electric vehicle routing problem using hyper-heuristic methods"**
>
> Submitted to **Applied Soft Computing Journal**
>
> Authors: Francisco Javier Gil Gala, Marko Đurasević and María Rita Sierra Sánchez
>
> Status: *In review*
>
> Manuscript reference: **ASOC-D-25-12027**



---

## 📂 Repository Content

- `data/` → Benchmark instances, datasets and configuration files used in the experiments.
- `results/` → Experimental results, performance metrics and analysis outputs.
- `README.md` → Repository documentation and usage information.

---

## 📊 Datasets

The datasets included in this repository are provided to
facilitate the reproducibility of the experiments described in the associated
manuscript.

Where possible, interoperable formats and documented experimental configurations
are included to support reuse and further research.

Please refer to the documentation available in each subdirectory for detailed
instructions.
