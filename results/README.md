# Results

## 📄 Description

This folder contains the experimental results and supplementary material for the paper:

> **"Evolving ensembles of routing policies for the electric vehicle routing problem using hyper-heuristic methods"**
>
> Submitted to **Applied Soft Computing Journal**
>
> Authors: Francisco Javier Gil Gala, Marko Đurasević and María Rita Sierra Sánchez
>
> Status: *In review*
>
> Manuscript reference: **ASOC-D-25-12027**

The material in this folder contains the data used to generate the figures, tables and statistical analyses reported in the manuscript.

---

## 📂 Folder Structure

- `StatisticalAnalysis_24_08_2026.xlsx` → Statistical analysis associated with several figures and one table from the paper.
- `SupplementaryMaterial_24_08_2026.xlsx` → Supplementary data containing the values used to generate all figures and tables in the manuscript.
- `open_formats/csv/` → Open-format CSV exports generated from the Excel workbooks to facilitate interoperability and reuse.
- `README.md` → Documentation of the results folder and file structure.
- `CHECKSUMS.txt` → SHA-256 checksums for integrity verification.

---

## 🔓 Open Formats

To improve compliance with FAIR principles and facilitate reuse with open tools,
all readable Excel sheets have been exported to CSV format.

The CSV exports are organised as follows:

- `open_formats/csv/StatisticalAnalysis_24_08_2026/`
- `open_formats/csv/SupplementaryMaterial_24_08_2026/`

Each CSV file corresponds to one worksheet from the original Excel workbook.

---

## 📊 Statistical Analysis Workbook

`StatisticalAnalysis_24_08_2026.xlsx` contains:

- Statistical analyses associated with selected figures and tables from the paper.
- Intermediate calculations and significance tests.
- Data transformations required for generating the reported statistical comparisons.
- Internal workbook documentation explaining the analysis process.

The corresponding CSV files preserve the tabular information in an interoperable format.

---

## 📈 Supplementary Material Workbook

`SupplementaryMaterial_24_08_2026.xlsx` contains:

- Data associated with all figures and tables reported in the manuscript.
- Experimental outputs and aggregated metrics.
- Intermediate values used during result generation and visualisation.

The workbook serves as the main supplementary source for reproducing the reported results.

---

## 📑 CSV Files

The CSV exports provide open-format representations of the workbook sheets.

These files are intended for:

- reproducibility,
- automated analysis,
- scripting with Python/R/Julia,
- and independent verification of the reported results.

Detailed column descriptions and sheet provenance are documented in the generated CSV metadata and workbook structure.

---

## 🧪 Reproducibility

To reproduce the analyses and figures reported in the paper:

1. Use the datasets contained in the `data/` folder.
2. Use the supplementary and statistical workbooks dated `24_08_2026` contained in this folder.
3. Prefer the corresponding CSV versions for automated processing pipelines.
4. Preserve the original filenames and workbook-sheet relationships.
